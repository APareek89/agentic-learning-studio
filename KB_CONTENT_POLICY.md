# KB Content Policy

As of: 2026-06-23

This knowledge base is built for retrieval-grounded lessons about agentic AI. It stores original synthesized notes, not copied documentation prose.

## Rules

- Use official project documentation first, then the project's own permissively licensed repository, then reputable expert or research sources.
- Do not copy source prose or code into KB docs. At most one short quote under 25 words is allowed when it is necessary and attributed.
- Store source text only in ignored raw caches for audit during build; ship only synthesized notes in kb/.
- Require provenance in frontmatter: title, category, url, license, as_of_date, and sources.
- Treat unknown, restrictive, GPL/AGPL, source-available, paywalled, or all-rights-reserved sources as facts-only references or skip them.
- Before embedding replacement, resolve every 🔴 audit item and manually review every 🟠 item.
- Date-stamp version-sensitive model, pricing, and API guidance.

## Attribution

KB docs cite source URLs in frontmatter and Key links. Citations are provenance, not permission to copy expression.

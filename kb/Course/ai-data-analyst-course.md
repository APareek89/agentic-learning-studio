## Who it's for

Data analysts, analytics engineers, BI practitioners, and operators who want to use AI for query drafting, metric explanations, anomaly investigation, forecasting, and insight communication while preserving analytical rigor.

## Prerequisites

- SQL fundamentals.
- Basic dashboard/BI experience.
- Comfort interpreting metrics, cohorts, and time series.

## Ordered modules

1. AI analytics foundations  
   Map to: AI Analytics and Natural Language BI, Data Foundations for AI Analytics. Outcome: understand where AI helps and where it can mislead.

2. Semantic layers and governed metrics  
   Map to: Data Foundations, Structured Outputs, Prompt Engineering. Outcome: define metrics, grains, dimensions, and permissions so AI can answer safely.

3. NL-to-SQL workflow  
   Map to: Structured Outputs and Function Calling, Tool Use, Prompt Injection. Outcome: generate, validate, and explain SQL without leaking data or inventing metrics.

4. Automated insight and anomaly workflows  
   Map to: AI Analytics, LLM Evaluation, Regression Testing. Outcome: turn metric changes into investigated hypotheses with evidence and caveats.

5. Forecasting and uncertainty  
   Map to: AI Analytics, Model Monitoring. Outcome: frame forecasts with backtests, confidence, seasonality, and business assumptions.

6. Communicating AI-assisted analysis  
   Map to: LLM-as-Judge, Guardrails, Data Governance. Outcome: create analyst review checklists and stakeholder-ready narratives with traceable sources.

## Capstone

Build an AI-assisted weekly growth review. It should accept a natural-language question, map it to governed metrics, produce validated SQL, explain the result, flag anomalies, include uncertainty, and document what a human analyst reviewed.
